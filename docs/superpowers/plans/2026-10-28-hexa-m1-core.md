# Hexa M1 (Core) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hexa runs on Fedora KDE (X11) as a transparent click-through overlay. Her original rigged character boots in, idles, sleeps, falls, can be dragged, and reacts to a real Claude Code session (ticker, alerts, victory, errors). Includes a tray, settings, English lines, synthesised sounds and a demo.

**Architecture:**
- An Electron main process (CommonJS) owns the overlay window, the X11 input shape, the Unix-socket bridge, the tray and the config.
- A sandboxed renderer (ES modules) draws Hexa on Canvas 2D:
  - a bone rig with verlet hair and cable chains
  - poses from exposure sheets played on twos
  - an FX layer
  - a DOM panel and ticker
  - a Brain that turns hook events into actions.
- The Claude Code hook is a self-contained Node script that posts trimmed events to the socket.

**Tech Stack:** Node ≥ 20, Electron 44.7.1, `x11` 4.3.1 (pure JS X11 client), `@fontsource/chakra-petch` 5.3.0, `@fontsource/jetbrains-mono` 5.3.0, `node:test`.

**Spec:** `docs/superpowers/specs/2026-10-28-hexa-design.md` (milestone M1, §14). Read §3, §4, §5, §6.1–6.2, §8, §9, §10 before starting.

**Upstream reference (MIT only):** tag `v0.4.3` of https://github.com/mochiiwuff/capri-desktop. Get it with:
`git clone https://github.com/mochiiwuff/capri-desktop.git /tmp/capri-ref && git -C /tmp/capri-ref checkout v0.4.3`.

## Global Constraints

- **Legal:**
  - Port code only from upstream `v0.4.3` or earlier.
  - Never read code from commits after `v0.4.3`.
  - Never use upstream `assets/`, `docs/` images or `lines.js` text.
  - Never draw or name the upstream character.
  - Every file containing ported code starts with `// Portions ported from capri-desktop v0.4.3 (MIT), see NOTICE.`
- **Character:** original Hexa per spec §4.2.
  - Palette: navy `#141a2e`, cyan `#3ef2ff`, amber `#ffb43a`, magenta `#ff3ea5`, white `#f4f7ff`.
  - State colours: idle cyan, thinking amber, waiting magenta, error `#ff4d4d`, done `#4dff9a`.
- **Versions (exact pins):** `electron` `44.7.1`, `x11` `4.3.1`, `@fontsource/chakra-petch` `5.3.0`, `@fontsource/jetbrains-mono` `5.3.0`. `"engines": { "node": ">=20" }`.
- **Paths:**
  - config `~/.config/hexa/config.json`
  - data `~/.local/share/hexa/`
  - logs `~/.local/state/hexa/`
  - socket `$XDG_RUNTIME_DIR/hexa/hexa.sock` (dir `0700`, socket `0600`); fallback when `XDG_RUNTIME_DIR` is unset: `~/.cache/hexa/hexa.sock`. Each base honours its `XDG_*` variable.
- **Bridge:** HTTP/1.1 over the socket.
  - Body limit 512 KB (413 above it).
  - Any request with an `Origin` header gets 403.
  - Optional TCP is off by default; when on: `127.0.0.1:47823` plus an `x-hexa-token` header.
- **Hook:** async, `timeout: 10`; strings cut at 280 chars, `content`/`old_string`/`new_string`/`new_source`/`edits` replaced by `<key>_len`; last reply cut at 6,000; always exits 0 within 2 s with no stdout.
- **Animation:**
  - Body sheets at 12 fps ("on twos"), 24 fps during teleports.
  - Physics and FX at display rate.
  - Every per-frame `dt` is clamped to 50 ms.
- **Timings:** thinking at 15 s / 40 s / 120 s; sleep after 10 min quiet; suspend 60 s after sleeping; working line every 20 tool calls; long job = 8 min or 50 actions.
- **Click-through:** X11 input shape (`ShapeInput`), updated at most 30 times a second; pointer-poll fallback at 30 Hz.
- **Renderer security:** `contextIsolation: true`, `sandbox: true`, `nodeIntegration: false`, a CSP, assets through `hexa://`. Untrusted text (events, replies, prompts) only through `textContent`/`createTextNode`, never `innerHTML`.
- **Shortcut:** `Ctrl+Alt+H` toggles background.
- **Style:** main process `'use strict'` CommonJS; renderer ES modules (`src/renderer/package.json` = `{"type":"module"}`). Comments explain why, in plain English, matching upstream's density.
- **Commits:** end every commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A stale socket file from a crash:** the next start must replace it, not fail with `EADDRINUSE`. A live instance must not be stolen from. Tested in Task 4.
2. **`~/.claude` missing, `settings.json` missing, empty, or invalid JSON:**
   - missing: install creates it
   - empty: treated as `{}`
   - invalid: install refuses and leaves the file byte-identical.
   Tested in Task 5.
3. **Monitors unplugged or resized while running** (the reference machine's second monitor comes and goes): the overlay refits, Hexa is clamped back inside the work area, and the input shape follows. Tested in Tasks 8 and 13.
4. **Huge time steps after suspend/resume or a frozen tab:** physics must not explode or produce NaN, and the thinking counter must not jump to "3600 s" after resume. Tested in Tasks 7, 9 and 12.
5. **Emoji and non-Latin text in prompts, paths and errors:** clipping must never split a surrogate pair. Tested in Tasks 3 and 6.

  - part: `{ id, bone, path (SVG path data in the bone's local space), fill, stroke?, z }`, where `fill`/`stroke` are palette keys
  - chain: `{ id, bone, x, y, segments, length, width: [base, tip], color, tip, z, stiffness, damping }`
  - glyph: `{ name: [leftRows[5], rightRows[5]] }`, each row 5 chars from `.#`.

  - spine: `root(0,0)` → `hips(0,-70)` → `spine(0,-38)` → `neck(0,-34)` → `head(0,-30)`

  - legs: `thighL/R` on `hips` at `(±12,0)` len 34, `shinL/R` len 32, `footL/R` len 10
  - cable: a chain on `spine` at `(-10,-20)`, 6 × 14
  - hair: 9 chains on `head` around the crown, 4 segments of 11–15
  - glyphs: `calm, smug, wide, laugh, squint, sleepy, angry, dizzy, heart, loading, ask, dead`.

  - `buildRig(pack) → rig`

  - `partBounds(rig, xf) → Map<partId, [x, y, w, h]>`
  - `hitRects(rig, xf, pad = 4) → Array<[x, y, w, h]>`: at most 12, merged

  - `head` is the head bone's angle; `tilt` is the root's rotation in degrees
  - `bob` is the root's y offset; `sx`/`sy` are the root's scale
  - `armL`/`armR` are the upper arms' angles, and `longL`/`longR` scale the forearms' length
  - `kickL`/`kickR` are the shins' angles
  - `dir` -1 mirrors x.
